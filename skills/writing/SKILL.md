# Writing

## Workflow

1. Identify the reader, the action or understanding they need, and what the user wants changed. Ask only if a missing detail would materially change the deliverable.
2. Read the guide for the requested format or standard. For a tone-only edit, start with the relevant style guide. Read another guide only when it solves a separate need. A small copyedit can use the workflow alone.
3. Preserve intent, facts, exact quotations, identifiers, numbers, attribution and degrees of certainty. Keep proposals distinct from commitments. If a template calls for unknown facts, omit optional fields or mark the gap. Examples in guides supply technique, never evidence.
4. Apply the user's brief and factual constraints first, then the required standard and format, then the requested voice, then optional stylistic preferences. Keep the author's register where the user has not requested a change.
5. Read the draft once as its recipient. Replace inflated claims with supplied facts, cut repetition, and keep everyday wording that fits. Treat vocabulary lists as editing prompts. Before delivery, trace each claim about how something works, what was decided, or what happens next to the supplied notes. Turn unsupported details into open questions or remove them. Check the chosen guide, caveats and length. Compare verbatim passages character for character, including punctuation. Move the attribution if it would change the quote.

## Output

Return the requested artifact in its intended format. Include editorial notes only when requested or when the user needs to resolve a material gap.
